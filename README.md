# 🔐 Random Password Generator  

A simple yet powerful password generator built with **vanilla JavaScript**.  
It creates secure, random passwords based on user-selected strength levels (Weak, Medium, Strong).  

👉 **Live Link:** [Random Password Generator](https://itslokeshx.github.io/passwordgenerator/)  

---

## ⚡ Features  
- ✅ Generate random passwords instantly  
- ✅ Choose strength levels:  
  - **Weak** → Numbers + Lowercase letters  
  - **Medium** → Numbers + Lowercase + Uppercase letters  
  - **Strong** → Numbers + Lowercase + Uppercase + Special characters  
- ✅ Copy password to clipboard with one click  
- ✅ Lightweight & beginner-friendly  

---

## 🛠️ Tech Stack  
- **HTML5** – Structure  
- **CSS3** – Styling  
- **JavaScript (Vanilla)** – Password generation logic  

---

## 🎯 How It Works  
1. Select the password strength level.  
2. Click **Generate** to create a new password.  
3. Hit **Copy** to save it to your clipboard.
